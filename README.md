# حمزاوي سات Android v0.2

تم ربط التطبيق مبدئيًا مع Backend v0.2 عبر REST API.

## المتصل فعليًا
- تحميل الخدمات من `/api/services`
- دخول الفني عبر `/api/auth/login`
- تسجيل الفني عبر `/api/auth/register`
- عرض رصيد الفني
- عرض الطلبات المتاحة
- تحذير + موافقة قبل فتح الطلب
- فتح الطلب وخصم الرصيد من السيرفر
- بعد نجاح الخصم تظهر بيانات العميل

## ملاحظة مهمة
إنشاء طلب العميل يحتاج حساب عميل لأن Backend v0.2 يحمي `/api/orders` بتسجيل دخول العميل.
لذلك شاشة حساب العميل/تسجيل الدخول هي الخطوة التالية.

## عنوان السيرفر
داخل `ApiClient.kt`:
`baseUrl = "http://10.0.2.2:3000"`

هذا مناسب عند تشغيل Backend على جهاز الكمبيوتر واستخدام Android Emulator.
على موبايل حقيقي على نفس Wi‑Fi يجب تغييرها إلى IP الكمبيوتر، مثل:
`http://192.168.1.10:3000`

لا تستخدم HTTP غير المشفر في الإنتاج؛ استخدم HTTPS.
